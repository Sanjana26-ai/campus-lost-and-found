# Campus Lost & Found

A campus-focused application for reporting and discovering lost and found items.

## Run locally

Requirements: Node.js (LTS) and npm.

```bash
npm install
npm run dev
```

Open the local URL printed in the terminal.

## Available scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build
- `npm run lint` — run ESLint
- `npm test` — run tests

## Data storage

The standalone demo stores submitted reports in the browser's local storage. Data is local to the browser and device; it is not shared between users or devices. Clearing browser storage removes saved demo reports.
